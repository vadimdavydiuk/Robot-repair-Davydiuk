# Лабораторна 9 — результати перевірки

Дата завершення: 13.11.2026. Версія: 1.0.

## Релізна Windows-збірка

- BuildTarget: StandaloneWindows64; звіт Unity: Succeeded, 0 помилок, 0 попереджень, 147351531 байт.
- Порядок сцен: MainMenu, MyLevel, MainScene.
- Вікно: 1280×720, віконний режим, зміна розміру дозволена.
- Релізний exe запущено окремим Windows-процесом. Візуально перевірено меню, кнопку «ГРАТИ», завантаження MyLevel, HUD і нормальне закриття вікна.
- У релізі немає сервера Unity Pipeline та коду StandaloneChecks: він компілюється лише в Development Build.

## Повний цикл поза редактором

Для автоматичної перевірки окремо зібрано Development exe з тією самою ігровою логікою. Unity збережено й закрито перед тестом. Перевірки запускаються лише параметром -lab9-smoke; звичайний запуск тестової збірки теж не викликає їх.

Усі 20 перевірок пройдені: окремий Player, перша сцена, запуск MyLevel, початкові HP і вороги, невразливість, звук/спалах, HUD, повернення кольору, аптечка, raycast NPC, діалог та його таймер, реальна фізична стіна, плита й закриття дверей, ремонт снарядом, перемога з блокуванням керування, перезапуск після перемоги, поразка та перезапуск після неї.

Автоматичний тест переміщує персонажа між перевірками. Він доводить роботу компонентів і завершень гри, але не є людським проходженням рівня від старту до фінішу й не використовується як статистика балансу або відео для Classroom.
