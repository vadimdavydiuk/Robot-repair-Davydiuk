## Щоденник розробника

### 24.09.2026 — Юніт 2: оточення і фізика

**Що зроблено:**
* Нарізано тайлсети `Floor` (Grid By Cell Count 3x3, PPU = 64) та намальовано розширену карту рівня з водяними перешкодами та бордюром за межами камери.
* Налаштовано сортування за віссю Y у `Renderer2D` (Custom Axis $Y = 1$) та змінено `Pivot` персонажа на середу ніг (Custom $X = 0.5$, $Y = 0$), що забезпечило коректний порядок відображення об'єктів (персонаж обходить декорації спереду й ззаду).
* Створено префаби для декорацій та зони шкоди `DamageZone` із режимом `Draw Mode = Tiled` (`Mesh Type = Full Rect`).
* Налаштовано фізику гравця: додано `Rigidbody 2D` ($Gravity\ Scale = 0$, $Freeze\ Rotation\ Z$) та `Box Collider 2D` на нижню частину спрайта.
* Перенесено рух персонажа у метод `FixedUpdate` через `rigidbody2d.MovePosition`, що повністю усунуло тремтіння при зіткненні з перешкодами.
* Налаштовано колізії тайлмапа через `Tilemap Collider 2D` та `Composite Collider 2D` ($Merge$, $Static$); для тайлів підлоги та Rule Tiles встановлено `Collider Type = None`.

**Що не вийшло або забрало найбільше часу:**
* Пошук причини тремтіння персонажа біля ящика (виправлено перенесенням обчислення позиції з `Update` до `FixedUpdate` із використанням `MovePosition`).
* Робот спочатку падав вниз після запуску сцени, оскільки забув скинути значення `Gravity Scale` до 0 в Inspector та застосувати зміни до префаба через `Overrides -> Apply All`.
* Стики між плитками води чіпляли персонажа під час руху вздовж берега до додавання компонента `Composite Collider 2D`.

**Що зрозумів про FixedUpdate і колайдери:**
* Зчитування вводу (`ReadValue<Vector2>`) потрібно виконувати в `Update` щокадру, щоб не пропускати натискання, а фізичний рух — у `FixedUpdate`, який викликається синхронно з фізичним рушієм (50 разів на секунду).
* Використання `rigidbody2d.MovePosition` замість прямої зміни `transform.position` дозволяє фізичному рушію коректно обробляти зіткнення без виштовхування та тремтіння.
* Встановлення `Collider Type = None` для підлоги залишає її прохідною, а `Composite Collider 2D` з об'єднанням ($Merge$) створює єдиний суцільний контур навколо непрохідних тайлів (води), запобігаючи застряганню на стиках.

**Що в рівні вийшло не так, як у фізичному паспорті, і чому:**
* Початкова ширина водойми виявилася занадто вузькою, тому довелося розширити зону з водою на 2 клітинки, щоб гравець обов'язково обходив її через створений місток, а не проскакував по краю.

**Що робитиму далі:**
* Перейду до Юніта 3: налаштування тригерних зон, додавання колекційних предметів (аптечок), системи здоров'я робота та механіки завдавання шкоди.

### 02.10.2026 — Юніт 3: система здоров'я

**Що зроблено:**
- Реалізовано систему здоров'я гравця через змінні `maxHealth`, `currentHealth` та властивість `health`.
- Створено функціонал зміни здоров'я `ChangeHealth()` з використанням `Mathf.Clamp`.
- Реалізовано таймер невразливості після отримання шкоди.
- Створено механіку аптечок (HealthCollectible) через тригери з перевіркою на максимальний рівень здоров'я.
- Створено зони шкоди (DamageZone) з використанням `OnTriggerStay2D` та налаштуванням `Never Sleep`.

**Що не вийшло або забрало найбільше часу:**
- Спочатку виникала помилка компіляції CS0122 через спробу звернутися до модифікатора доступу private. Вирішив це створенням властивості `health { get { return currentHealth; } }`.

**Що зрозумів про тригери, public і private:**
- Звичайні колайдери блокують рух, а тригери реєструють факт перебування об'єкта у зоні без фізичного перешкоджання.
- Модифікатор `public` дозволяє бачити змінні в Inspector та звертатися до них з інших скриптів, а властивості `get` дозволяють захистити дані від випадкового перезапису іншими класами.

**Яке значення Time Invincible обрав і для якого гравця:**
- Встановив значення `1.5` секунди. Це дає гарний баланс для помірно досвідченого гравця: є час вибігти з небезпечної зони, але стояння на місці швидко виснажує запас здоров'я.

**Що робитиму далі:**
- Переходжу до Юніту 4: створення ворогів та їхньої поведінки.

## Як запустити виправлену версію

Unity Hub → Add project from disk → ця тека проєкту. Версія редактора: 6000.3.23f1.
Відкрити Assets/_2DAdventureGame/Scenes/MyLevel.unity та натиснути Play.
Рух: WASD / стрілки. C — ремонтний снаряд. X — розмова, коли дивишся на NPC зблизька.
Полагодити всіх трьох роботів — перемога; втратити все здоров’я — поразка. В обох випадках через 3 секунди перезапускається активна сцена.

Детальна перевірка лабораторних, план рівня, пояснення механіки й перелік матеріалів для здачі: Docs/Labs-Review-UK.md.
